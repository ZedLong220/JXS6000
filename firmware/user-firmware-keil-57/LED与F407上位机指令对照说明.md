# LED 与 F407 上位机指令对照说明

## 1. 系统关系

系统由两部分组成：

- F407 主控：接收 USART1 串口字符串命令，并通过 CAN 控制 6 个驱动板。
- 驱动板：每块板控制 1 个电机，CAN 节点 ID 对应 J1~J6。

CAN 标准帧 ID 规则：

```text
标准帧 ID = (节点 ID << 7) | 命令字
```

节点 ID 分配：

| 节点 ID | 对应关节 |
|---:|:---|
| 0 | 广播，全部电机 |
| 1 | J1 |
| 2 | J2 |
| 3 | J3 |
| 4 | J4 |
| 5 | J5 |
| 6 | J6 |

F407 串口为 USART1，波特率 115200。每条命令需要以回车、换行或回车换行结束。

## 2. 驱动板 LED 接口

| LED | STM32 引脚 | 代码编号 |
|:---|:---|---:|
| LED1 | PC13 | 0 |
| LED2 | PC14 | 1 |

当前驱动板代码中的电平映射为：

```cpp
_state ? GPIO_PIN_RESET : GPIO_PIN_SET
```

LED 的具体亮灭还取决于 PCB 上 LED 的有效电平。下表同时给出代码逻辑状态和目前实测现象，以实测现象为现场判断依据。

## 3. 全部 LED 状态

### 3.1 代码状态枚举

| 状态值 | 状态名 | 进入条件 | LED1 代码逻辑 | LED2 代码逻辑 |
|---:|:---|:---|:---|:---|
| 0 | `STATE_STOP` | 停止、急停、`stop` 后 | 常态 `false` | 不闪烁，常态 `false` |
| 1 | `STATE_FINISH` | 位置、速度或电流目标已完成 | 常态 `true` | 不闪烁，常态 `false` |
| 2 | `STATE_RUNNING` | 电机正在执行目标 | 心跳闪烁 | 不闪烁，常态 `false` |
| 3 | `STATE_OVERLOAD` | 过载保护 | 常态 `true` | 3 次闪烁 |
| 4 | `STATE_STALL` | 堵转保护 | 常态 `false` | 2 次闪烁 |
| 5 | `STATE_LIMIT` | 限位保护有效 | 常态 `false` | 4 次闪烁 |
| 6 | `STATE_NO_CALIB` | 编码器尚未校准 | 常态 `false` | 1 次闪烁 |

### 3.2 用户当前实测现象

| 使用场景 | LED1 | LED2 | 含义 |
|:---|:---|:---|:---|
| 上电后、没有发送运动指令 | 常亮 | 常亮 | 驱动板处于停止或待机状态 |
| 位置模式运动中，例如 `j1:180` | 闪烁 | 常亮 | 电机正在运动 |
| 位置模式到达目标 | 熄灭 | 常亮 | 电机已到位 |
| 电流模式运行，例如 `current:1,1.5` | 闪烁提示 | 常亮 | 电机处于电流控制状态 |
| 执行 `stop` 后 | 常亮 | 常亮 | 电机停止，输出被清零 |
| 堵转保护 | 常态灯保持当前停止显示 | LED2 2 次闪烁 | `STATE_STALL` |
| 过载保护 | LED1 熄灭 | LED2 3 次闪烁 | `STATE_OVERLOAD` |
| 限位保护 | LED1 常亮 | LED2 4 次闪烁 | `STATE_LIMIT` |
| 未校准 | LED1 常亮 | LED2 1 次闪烁 | `STATE_NO_CALIB` |

### 3.3 闪烁节拍

- LED1 运动心跳：约 100 ms 亮、100 ms 灭、100 ms 亮，随后约 700 ms 间隔，循环执行。
- LED2 故障提示：每次闪烁约 100 ms，完成指定次数后暂停约 1 s，再重复。
- LED2 闪烁次数：1 次表示未校准，2 次表示堵转，3 次表示过载，4 次表示限位。

### 3.4 限位 LED 与限位输入

驱动板限位输入为低电平有效：

| 输入 | 含义 |
|:---|:---|
| PB0 | 左限位 |
| PB1 | 右限位 |
| PB0=1、PB1=1 | 没有触发限位 |
| PB0=0、PB1=1 | 左限位触发 |
| PB0=1、PB1=0 | 右限位触发 |
| PB0=0、PB1=0 | 左右限位同时触发 |

任意限位输入变低时，驱动板会清零位置、速度和电流目标，清除控制积分，并关闭驱动输出。随后通过 CAN `0x32` 上报限位事件。触发限位的一侧禁止继续向限位方向运动，允许反向退出限位。

## 4. F407 基础机械臂命令

以下命令通过 F407 的 USART1 发送。角度命令中的角度单位为度。

| 命令格式 | 作用 | 典型回显或结果 |
|:---|:---|:---|
| `j1:0,j2:30,j3:150,j4:0,j5:-90,j6:0` | 六轴运动到指定角度 | 输出 `[CMD] move:`，完成后输出 `move done` |
| `j1:50` | 仅 J1 运动到 50 度，其他轴保持目标 | 输出对应运动结果 |
| `j2:50,speed:10` | J2 运动到 50 度，本次使用 10 度/秒 | 输出运动结果 |
| `speed` | 查询默认关节速度 | `[CMD] move speed = ... deg/s` |
| `speed:20` | 设置默认关节速度为 20 度/秒 | 输出默认速度设置结果 |
| `home` | 回机械臂默认姿态 | 输出 `[CMD] home` |
| `homing` | J6→J1依次寻找右限位并建立本次运行零点 | 输出各轴找限位和设零进度 |
| `sethome` | 把当前位置记录为新的 home 姿态 | 输出 `[CMD] sethome` |
| `stop` | 广播急停全部电机，并停止点位循环 | 输出 `[CMD] stop` |
| `status` | 查询机械臂状态和末端位姿 | 输出当前关节、状态和位姿 |
| `p` | `status` 的简写 | 同 `status` |
| `rpos` | 从 6 个驱动板读取实际编码器位置 | 输出实际角度、目标角度、误差和到位标志 |
| `movel:0.300,0.100,0.200,0.050` | 笛卡尔直线运动 | XYZ 单位 m，速度单位 m/s |

说明：

- `homing` 是机械回零。它固定按 J6、J5、J4、J3、J2、J1 的顺序执行，每个关节向 PB1 右限位运动；右限位触发后，F407 发送 CAN `0x33`，驱动板把当前位置设为本次运行的零点并返回确认。
- `0x33` 只修改 RAM 中的运行时零点，不修改 `boardConfig`，也不触发 `CONFIG_COMMIT`，因此不会写 EEPROM。重新上电后必须再次执行 `homing`。
- `home` 是在机械回零完成后回到 F407 保存的机械臂 home 姿态；`sethome` 只修改主控的软件 home 参考，不改变机械零点。
- 上电后尚未完成 `homing` 时，主控拒绝普通关节运动、点位运动和笛卡尔运动。回零执行期间仅允许 `status`、`p` 和 `stop`；`stop` 可以随时中止回零。

电机 ID 使用 `0~6`：`0` 表示全部电机，`1~6` 表示指定 J1~J6。

| 命令格式 | 别名 | 作用 | 单位 |
|:---|:---|:---|:---|
| `enable:1` |  | 使能 J1 | 无 |
| `enable:0` |  | 使能全部电机 | 无 |
| `enable:0,0` | `disable:0` | 失能全部电机 | 无 |
| `enable:0,1` |  | 广播使能全部电机 | 无 |
| `disable:3` |  | 失能 J3 | 无 |
| `calib:0` | `calibration:0` | 校准全部电机 | 无 |
| `calib:2` | `calibration:2` | 校准 J2 | 无 |
| `pos1:2` | `circle1:2`、`first:2` | J2 转到第 1 圈 | 圈 |
| `current:1,1.5` | `runcur:1,1.5` | J1 以 1.5 A 电流运行 | A |
| `current:0,1.0` |  | 全部电机以 1.0 A 电流运行 | A |
| `pos:6,10` | `circle:6,10` | J6 运行到第 10 圈 | 圈 |
| `velocity:2,1.2` | `vel:2,1.2` | J2 按 1.2 rad/s 连续运行 | rad/s |
| `stop` |  | 清零速度、电流并急停全部电机 | 无 |

电流、速度模式收到限位保护时，当前输出会被清零。触发侧禁止继续向限位方向运动，只允许反方向退出。

### 5.1 电机 ID1 实测转动方向

当前电机接线和驱动程序下，电机 ID1（J1）的位置、速度和电流命令方向实测如下：

| 控制模式 | F407 串口命令 | 命令值 | 实测转动方向 |
|:---|:---|---:|:---|
| 位置 | `pos:1,-10` / `circle:1,-10` | -10 圈 | 顺时针旋转 |
| 位置 | `pos:1,10` / `circle:1,10` | +10 圈 | 逆时针旋转 |
| 速度 | `velocity:1,-1.0` / `vel:1,-1.0` | -1.0 rad/s | 顺时针旋转 |
| 速度 | `velocity:1,1.0` / `vel:1,1.0` | +1.0 rad/s | 逆时针旋转 |
| 电流 | `current:1,-1.0` / `runcur:1,-1.0` | -1000 mA（-1.0 A） | 顺时针旋转 |
| 电流 | `current:1,1.0` / `runcur:1,1.0` | +1000 mA（+1.0 A） | 逆时针旋转 |

因此，ID1 的负位置、负速度和负电流方向为顺时针；正位置、正速度和正电流方向为逆时针。

### 5.2 电机 ID2 实测转动方向

当前电机接线和驱动程序下，电机 ID2（J2）的位置、速度和电流命令方向实测如下：

| 控制模式 | F407 串口命令 | 命令值 | 实测转动方向 |
|:---|:---|---:|:---|
| 位置 | `pos:2,-10` / `circle:2,-10` | -10 圈 | 逆时针旋转 |
| 位置 | `pos:2,10` / `circle:2,10` | +10 圈 | 顺时针旋转 |
| 速度 | `velocity:2,-1.0` / `vel:2,-1.0` | -1.0 rad/s | 逆时针旋转 |
| 速度 | `velocity:2,1.0` / `vel:2,1.0` | +1.0 rad/s | 顺时针旋转 |
| 电流 | `current:2,-1.0` / `runcur:2,-1.0` | -1000 mA（-1.0 A） | 逆时针旋转 |
| 电流 | `current:2,1.0` / `runcur:2,1.0` | +1000 mA（+1.0 A） | 顺时针旋转 |

因此，ID2 的正位置、正速度和正电流方向均为顺时针；负位置、负速度和负电流方向均为逆时针。
这里的顺时针和逆时针采用当前现场测试时的观察方向；如果改从电机另一侧观察，视觉方向会相反。该结论只记录 ID2 当前接线，不代表 ID1、ID3~ID6 必然具有相同方向。

## 6. 限位相关串口命令

### 6.1 六轴机械回零

```text
homing
```

回零流程如下：

1. F407 先停止全部电机并清除旧限位事件。
2. 按 J6→J5→J4→J3→J2→J1 的顺序，每次只向一个驱动板发送找右限位命令 `0x31`。
3. 当前驱动板检测到 PB1 为低电平后立即停止，并通过 `0x32` 回报右限位事件。
4. F407 检查节点、限位方向和 `fromCommand` 标志后，发送运行时设零命令 `0x33`。
5. 驱动板重新建立连续位置基准，返回 `0x33` 确认，但不写 EEPROM。
6. 收到确认后才开始下一个关节；任何错误方向、意外节点、超时或确认失败都会停止全部电机。

J6 使用较低的找限位速度；J1~J5 根据减速比使用各自速度和超时。回零过程中只能使用 `status`、`p` 查看状态，或发送 `stop` 立即中止。

### 6.2 移动到左限位

```text
limitl:1
limitl:1,2.0
leftlimit:1,1.5
```

- `1` 表示 J1，使用 `0` 表示 6 个电机一起执行。
- 速度单位为电机圈/秒。
- 不填写速度或填写 0 时，由驱动板使用默认找限位速度。
- 左限位固定对应驱动板 PB0。
- 驱动板检测到限位后立即停止，并发送 CAN `0x32`。

### 6.3 移动到右限位

```text
limitr:3
limitr:3,2.0
rightlimit:1,1.5
```

右限位固定对应驱动板 PB1，其他规则与左限位相同。

### 6.4 查询限位状态

```text
limit
limit:status
limit:3
```

输出示例：

```text
[LIMIT] current status:
  driver 1: LEFT (state=5 input=1)
  driver 2: NONE (state=0 input=0)
```

状态文字含义：`NONE` 无限位，`LEFT` 左限位，`RIGHT` 右限位，`BOTH` 左右同时触发。

当查询发现任意驱动板当前有限位输入有效时，F407 会发送广播急停 `CAN_StopAll()`，并输出：

```text
[EMERGENCY] active limit input detected; all motors stopped
```

## 8. 点位命令

点位编号范围为 1~200。点位命令默认只修改 RAM，执行 `point:store` 后才永久写入 Flash。

| 命令格式 | 作用 |
|:---|:---|
| `point:set,1,j1:0,j2:30,j3:150,j4:0,j5:-90,j6:0` | 将六轴角度写入 RAM 中的 P1 |
| `point:save,1` | 从 6 个驱动板读取实际位置，保存为 P1 |
| `point:get,1` | 查询 P1 |
| `point:list` | 列出全部已记录点位 |
| `point:move,1` | 按默认速度运动到 P1 |
| `point:move,1,15` | 按 15 度/秒运动到 P1 |
| `point:clear,1` | 清除 RAM 中的 P1 |
| `point:clear,0` | 清除 RAM 中全部点位 |
| `point:store` | 将当前 RAM 点位整体写入 Flash |
| `point:load` | 从最近一次 Flash 快照重新载入点位 |

点位运动开始前会执行关节限位检查和穿地检查。运动中执行 `stop` 会停止电机并取消相关点位循环。

## 9. 点位循环命令

命令格式：

```text
loop:first,last,count[,speed]
```

| 命令格式 | 作用 |
|:---|:---|
| `loop:1,3,5` | P1 到 P3，循环 5 次，使用默认速度 |
| `loop:3,1,5,20` | P3 到 P1，循环 5 次，速度 20 度/秒 |
| `loop` | 查询当前循环状态 |
| `loop:stop` | 停止循环并急停电机 |

循环期间允许执行 `status`、`p`、`loop`、`loop:stop` 和 `stop`。发生限位、穿地保护、错误或点位超时，循环会被取消。

| 笛卡尔轨迹同步 | `0x66` | 广播提交并同步启动已缓存轨迹 |

### 10.1 CAN 返回帧说明

#### 位置返回 `0x23`

```text
data[0..3] = 当前电机位置 float，单位：圈
data[4]    = 1 表示到位，0 表示运动中
```

#### 限位事件 `0x32`

驱动板检测到限位并停止后，主动发送：

```text
data[0] = 0：无限位
          1：左限位 PB0
          2：右限位 PB1
          3：左右同时触发
data[1] = 1：由 limitl/limitr 找限位命令触发
          0：普通运动过程中触发
data[2] = 限位事件发生时的驱动板状态，通常为 STATE_LIMIT=5
data[3] = 当前限位输入位图，1=左，2=右，3=双边
```

CAN 帧 ID 为：

```text
(驱动板节点 ID << 7) | 0x32
```

F407 收到 `0x32` 后会打印类似信息：

```text
[LIMIT] driver 1 triggered LEFT limit, fromCmd=1 state=5 input=1
[EMERGENCY] limit event detected; all motors stopped
```

#### 运行时设零 `0x33`

F407 向当前回零轴发送空数据帧 `0x33`。驱动板仅在 PB1 右限位单独有效时接受该命令；接受后将当前位置设为运行时零点、重置连续多圈位置和运动规划目标，然后回复：

```text
data[0] = 1：运行时设零完成；0：拒绝设零
data[1] = 当前限位输入位图，正常回零时必须为 2（RIGHT）
```

该命令不更新 EEPROM；原有 `0x15` 仍保留为需要持久化时使用的 home offset 命令。

#### 当前限位查询 `0x35`

驱动板收到 F407 的 `0x35` 查询后返回：

```text
data[0] = 当前限位方向：0 无、1 左、2 右、3 双边
data[1] = 当前驱动板状态
data[2] = 当前限位输入位图：1 左、2 右、3 双边
```

## 10.2 CAN 通用帧格式

当前驱动板和 F407 使用标准 CAN 数据帧，不使用扩展帧和远程帧：

| 字段 | 当前值或规则 |
|:---|:---|
| 帧格式 | 标准帧，11 bit 标准 ID |
| 帧类型 | 数据帧，`RTR = DATA` |
| DLC | 当前发送接口统一为 8 |
| CAN 波特率 | 1 Mbps |
| 标准 ID | `(nodeId << 7) | cmd` |
| 数据字节序 | 小端序（Little Endian） |
| `float` | IEEE-754 单精度，占 4 字节，放在 `data[0..3]` 或 `data[4..7]` |
| `int32_t` / `uint32_t` | 小端序，占 4 字节 |
| 未使用字节 | 填 0 |

例如，J1 的命令 ID 为 `1 << 7 = 0x080`：

| 目标 | 命令字 | CAN 标准 ID |
|:---|---:|---:|
| J1 使能 | `0x01` | `0x081` |
| J1 电流 | `0x03` | `0x083` |
| J1 位置查询 | `0x23` | `0x0A3` |
| J1 左限位 | `0x30` | `0x0B0` |
| J1 右限位 | `0x31` | `0x0B1` |
| J1 限位事件 | `0x32` | `0x0B2` |
| J1 限位查询 | `0x35` | `0x0B5` |

广播命令使用节点 ID 0，因此广播急停 `0x09` 的标准 ID 是 `0x009`，广播轨迹同步 `0x66` 的标准 ID 是 `0x066`。

## 10.3 CAN 发送命令完整格式

下面的 `ID` 均为标准帧 ID，`DLC` 均为 8。示例中的数据字节按小端序排列。

| 命令字 | 功能 | `data[0..3]` | `data[4]` | `data[5..7]` |
|---:|:---|:---|---:|:---|
| `0x01` | 使能/失能 | `uint32`：1 使能，0 失能 | 0 | 0 |
| `0x02` | 校准 | 不使用 | 0 | 0 |
| `0x03` | 电流控制 | `float`：运行电流，A | 0 | 0 |
| `0x04` | 速度控制 | `float`：速度值 | 0 | 0 |
| `0x05` | 位置控制 | `float`：目标位置，电机圈 | `0` 不请求即时应答，非 0 请求返回 `0x23` | 0 |
| `0x06` | 位置+时间 | `float`：目标位置，电机圈 | `float` 时间的低字节，从 `data[4]` 开始 | 时间的高 3 字节在 `data[5..7]` |
| `0x07` | 位置+速度限制 | `float`：目标位置，电机圈 | `float` 速度限制的低字节，从 `data[4]` 开始 | 速度的高 3 字节在 `data[5..7]` |
| `0x08` | 缓存轨迹点 | `float`：目标位置，电机圈 | `float` 执行时间的低字节，从 `data[4]` 开始 | 时间的高 3 字节在 `data[5..7]` |
| `0x09` | 广播急停 | 0 | 0 | 0 |
| `0x11` | 设置节点 ID | `uint32`：新节点 ID | `data[4]=1` 请求保存 | 0 |
| `0x12` | 设置电流限制 | `float`：电流限制，A | `data[4]=1` 请求保存 | 0 |
| `0x13` | 设置转速限制 | `float`：转速限制，圈/s | `data[4]=1` 请求保存 | 0 |
| `0x14` | 设置加速度 | `float`：加速度，圈/s^2 | `data[4]=1` 请求保存 | 0 |
| `0x15` | 应用当前位置为 home | 0 | 0 | 0 |
| `0x16` | 设置开机自动使能 | `uint32`：1 开启，0 关闭 | `data[4]=1` 请求保存 | 0 |
| `0x17` | 设置 DCE Kp | `int32` | `data[4]=1` 请求保存 | 0 |
| `0x18` | 设置 DCE Kv | `int32` | `data[4]=1` 请求保存 | 0 |
| `0x19` | 设置 DCE Ki | `int32` | `data[4]=1` 请求保存 | 0 |
| `0x1A` | 设置 DCE Kd | `int32` | `data[4]=1` 请求保存 | 0 |
| `0x1B` | 设置堵转保护 | `uint32`：1 开启，0 关闭 | `data[4]=1` 请求保存 | 0 |
| `0x21` | 查询当前电流 | 0 | 0 | 0 |
| `0x22` | 查询当前速度 | 0 | 0 | 0 |
| `0x23` | 查询当前位置 | 0 | 0 | 0 |
| `0x24` | 查询 home 偏移 | 0 | 0 | 0 |
| `0x25` | 查询温度 | 0 | 0 | 0 |
| `0x26` | 查询电流限制 | 0 | 0 | 0 |
| `0x27` | 查询转速限制 | 0 | 0 | 0 |
| `0x28`~`0x2B` | 查询 DCE Kp/Kv/Ki/Kd | 0 | 0 | 0 |
| `0x30` | 移动到左限位 | `float`：找限位速度，圈/s；0 表示驱动板默认速度 | 0 | 0 |
| `0x31` | 移动到右限位 | `float`：找限位速度，圈/s；0 表示驱动板默认速度 | 0 | 0 |
| `0x35` | 查询当前限位输入 | 0 | 0 | 0 |
| `0x7D` | 开启温度监控 | 不使用 | 0 | 0 |
| `0x7E` | 擦除驱动板配置 | 不使用 | 0 | 0 |
| `0x7F` | 驱动板复位 | 不使用 | 0 | 0 |
| `0x66` | 广播提交轨迹 | `data[0]=0xFF`，`data[1]=0x66` | 0 | 0 |

注意：`0x06` 和 `0x08` 的 8 字节数据是两个连续的 `float`，即 `data[0..3]` 为位置，`data[4..7]` 为时间；`0x07` 同理是位置加速度限制。`0x05` 的 `data[4]` 是明确的位置应答请求标志。参数保存类命令 `0x11~0x14`、`0x16~0x1B` 使用 `data[4]=1` 表示请求保存。

当前驱动板对位置命令的应答行为如下：

- `0x05`：仅当 `data[4]` 非 0 时立即返回一次 `0x23`。
- `0x06`：`data[4]` 本来是时间 float 的第一个字节，但当前驱动代码也用它判断是否立即返回 `0x23`，因此这个即时应答不稳定，F407 不依赖它判断运动完成。
- `0x07`：每次命令都会立即返回一次 `0x23`。
- `0x08`：只缓存轨迹，不返回位置；收到广播 `0x66` 后开始执行。
- F407 判断运动完成时会主动轮询 `0x23`，以返回帧 `data[4]` 的到位标志为准。

| `0x26` 电流限制 | `float`：原始值，mA | 0 | 0 |

| `0x2A` | `float`：DCE Ki | 0 | 0 |
| `0x2B` | `float`：DCE Kd | 0 | 0 |

`0x21`~`0x23` 的查询请求数据全部为 0，返回帧一般为 8 字节。F407 的 `rpos` 主要使用 `0x23`；`getparam`、`getcur`、`getvel`、`getpid` 分别使用 `0x26`、`0x27` 和 `0x28`~`0x2B`。

## 10.5 数据单位和换算说明

- 驱动板内部每电机一圈使用 `200 * 256 = 51200` 个细分位置单位。
- `0x05`、`0x06`、`0x07`、`0x08` 的位置参数是电机圈数，不是机械臂关节角度。
- F407 发送关节角度时，会根据 `REDUCTION_J1~J6` 和 `DIRECTION_J1~J6` 将关节角度换算成电机圈数。
- `0x03` 的运行电流使用 A；`0x12` 的设置参数使用 A，驱动板内部保存为 mA。
- `0x26` 的驱动板原始返回值是以 mA 表示的 float，例如 1000 mA 返回 `1000.0`，F407 查询函数再除以 1000 输出 `1.000 A`。
- F407 串口 `velocity:id,value` 当前按 rad/s 解析并发送，但驱动板 `0x04` 直接按 `value * 51200` 换算内部步/s；如果用 CAN 分析仪直接发 `0x04`，建议按驱动板实现采用电机圈/s，并在主控与驱动板两端统一单位。

## 10.6 旧接口说明

F407 `can_protocol.c` 中还保留了两个旧接口：

| 旧接口 | 帧 ID 命令 | 说明 |
|:---|:---:|:---|
| `CAN_SetZero()` | `0x6D` | 旧的设置零位命令；当前驱动板 `interface_can.cpp` 没有对应的 `case 0x6D`，不能作为当前协议使用 |
| `CAN_Home()` | `0x02` | 旧的回零数据格式；当前 `0x02` 在驱动板中用于编码器校准，当前串口命令应使用 `calib`/`calibration` |

因此，当前工程应以本节前面的 `0x01~0x09`、`0x11~0x1B`、`0x21~0x2B`、`0x30~0x35` 和 `0x66` 为准。

## 10.7 串口命令到 CAN 帧的发送流程

| F407 串口命令 | F407 实际发送的 CAN 帧 | 发送次数 |
|:---|:---|:---:|
| `j1:50` 等关节位置命令 | 对被指定的关节发送节点帧 `0x06`；未指定关节保持原目标。当前 `Arm_MoveToAngles` 流程不再额外发送 `0x66` | 1~6 |
| `movel:X,Y,Z,speed` | 主控计算笛卡尔插补后，循环发送各轴 `0x08`，最后广播 `0x66` | 多帧 + 1 |
| `point:move,id` | 对各轴发送 `0x06`，并通过后续 `0x23` 查询到位 | 多帧 |
| `enable:id` / `disable:id` | 目标节点 `0x01` | 1 或广播 |
| `calib:id` | 目标节点 `0x02` | 1 或广播 |
| `current:id,A` | 目标节点 `0x03` | 1 或广播 |
| `velocity:id,V` | 目标节点 `0x04` | 1 或广播 |
| `pos:id,rev` | 目标节点 `0x05` | 1 或广播 |
| `limitl:id[,rps]` | 目标节点 `0x30` | 1 或广播 |
| `limitr:id[,rps]` | 目标节点 `0x31` | 1 或广播 |
| `limit[:id|status]` | 目标节点 `0x35`，等待返回；发现有效限位时再广播 `0x09` | 1~6，必要时 + 1 |
| `rpos` | 对 J1~J6 逐个发送 `0x23`，等待返回 | 6 |
| `status` / `p` | 主控查询位置并计算状态，非运动状态主要使用 `0x23` | 多帧 |
| `setcur:jN,A` | 目标节点 `0x12`，`data[4]=1` 保存 | 1 |

| `getvel:jN` | 发送 `0x27`，等待返回 | 1 |

| CAN 命令 | 功能 | DATA 格式 |
|---:|:---|:---|

| `0x7D` | 开启温度监控 | DATA 全 0 |

## 12. 注意事项

1. 串口命令必须带行结束符，否则 F407 可能继续等待后续字符。
2. 发送 `current` 或 `velocity` 后，电机可能处于持续运行模式；需要发送 `stop` 才会清零输出。
3. 驱动板限位输入为低电平有效，PB0 是左限位，PB1 是右限位。
4. 限位保护停止后，只允许反方向退出触发侧；继续向触发侧运动的目标、速度和电流会被清零。
5. `limit` 查询发现有效限位时，F407 会广播停止全部电机，不仅停止被查询的单个电机。
6. `point:store` 才会把点位修改永久保存到 Flash；只执行 `point:set` 或 `point:clear`，重启后可能恢复旧快照。
7. 角度单位、驱动板电机圈数和关节减速比由 F407 `can_protocol.h` 中的关节配置决定。更换电机或减速机构后，应同步检查 `REDUCTION_J1~J6` 和方向配置。
8. 电机 ID1 当前实测方向为：负圈数、负速度和负电流顺时针，正圈数、正速度和正电流逆时针。
9. 电机 ID2 当前实测方向为：正圈数、正速度和正电流顺时针，负圈数、负速度和负电流逆时针；更换相线、驱动板或观察方向后必须重新确认。
