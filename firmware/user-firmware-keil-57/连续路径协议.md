# 无刹车42步进电机：六轴连续路径协议 v4

更新日期：2026-11-09。本固件直接驱动电机并使用板载编码器闭环。六块相同硬件可烧录同一个HEX，配套新版V6000主控和新版SmallProject上位机。

## 地址设置

J1/J2/J3/J4/J5/J6对应节点1/2/3/4/5/6。上电从三个拨码读取ID，覆盖EEPROM中的节点号；不能仅靠保存CAN地址后不改拨码。

代码映射：Switch4/PA8=bit0，Switch3/PA9=bit1，Switch2/PA10=bit2；低电平为1。按有效位列出：

| 节点 | bit2 bit1 bit0 |
|---|---|
| 1 | 0 0 1 |
| 2 | 0 1 0 |
| 3 | 0 1 1 |
| 4 | 1 0 0 |
| 5 | 1 0 1 |
| 6 | 1 1 0 |

各板地址唯一，改拨码后重启。J6为实体轴，使用节点6。夹爪由F407的PA0独立PWM控制，不占用CAN关节节点。各板保留自己的电流、编码器校准及零位设置，不能用一块板的校准数据覆盖另一块板。

## CAN协议

标准ID=node<<7|command，1Mbps；float为小端IEEE754，seq/session为小端uint16。

| 命令 | 数据 | 作用 |
|---|---|---|
| 0D | DLC2 session | 清空曲线、抱住编码器实测位置并建立新会话 |
| 0A | DLC8 p0,p1 float（电机圈） | 一段起终点 |
| 0B | DLC8 v0,v1 float（圈/秒） | 一段起终速度 |
| 0C | DLC8 时间float,seq,session | 提交段，seq从0连续，最多32段 |
| 3C请求 | DLC0 | 查询状态并喂500ms心跳看门狗 |
| 3C响应 | 04,state,count,index,error,05,sessionLo,sessionHi | 协议4，能力05=板载编码器+连续路径 |
| 39请求 | DLC0 | 能力响应04,05,20,00,00,00,00,00 |
| 广播66 | FF,66,04,mask,count,repeat,sessionLo,sessionHi | 选中节点同步启动，延迟20ms |
| 广播67 | FF,67,04,mask,count,00,sessionLo,sessionHi | 非循环路径同步收尾，参与轴同时置零速度并锁定终点 |
| 0E | DLC0或兼容原长度 | 普通停止：取消曲线并继续位置闭环抱住当前位置 |
| 09 | 兼容原停止长度 | 故障/紧急失能：停止、清除路径并关闭驱动输出 |
| 23 | DLC0 | 原累计多圈编码器float及finished反馈 |

mask bit0～bit5=节点1～6，六轴3F，J2/J3为06。不在mask内的节点忽略启动和收尾。只有正确版本、会话、段数及已校准/起点允许时才能启动。非循环路径由主控在统一终点前约2ms广播67，六块参与板在同一CAN帧中锁定各自最终位置；循环路径不发送67。旧两字节FF66的单次同步兼容保留；旧八字节协议2/3不再启动新版连续运动。

0C在CAN中断暂存，前台验证时间、速度、加速度、p/v连续性后增加count。主控核对所有参与板count/session再装下一段，整条路径装完才广播启动。超限拒绝，不会单轴静默降速破坏同步。速度、电流、加速度沿用各板EEPROM限制。

旧式定时点位06/08使用位置圈数和时间秒数反算梯形速度上限。2026-11-20补充
该通道的板内限速约束：反算值不能超过EEPROM的velocityLimit，时间不足则按保存
的限速运动，由主控继续校验实测到位。反算使用稳定公式，避免短行程因浮点相减
抵消而算出零速；位置规划达到速度上限时清理残留加速度，避免进入匀速后短暂
超过上限。对应MotionPlanner::TimedPositionVelocityLimit，固定取放路径
去程/回零6.56秒需配套此驱动；各板加速度仍取各自EEPROM，不由上位机覆盖。

## 执行与保护

BufferedPath为五次Hermite执行器，各段端点加速度0；非循环路径初始和最终速度为0，循环路径须位置和速度同时闭合。第一次使用专用首段从0速起步，后续圈按闭合速度连续执行；新版上位机已对循环接缝做双侧圆滑，不再固定每圈停车。所有轴共用段时间；运动中不依赖网络逐段追发。

驱动板上电约100ms后启动闭环；编码器已校准且无保护故障时自动进入位置使能，并把第一次编码器实测位置作为保持目标，因此只在当前位置抱紧，不会自动回零或跳到EEPROM零位。该策略会覆盖旧EEPROM中保存的“上电不使能”选项。路径装载、普通停止、主控路径/通讯故障、运动完成以及后续多次运动之间均保持位置闭环。每次从路径切回保持时以当前编码器位置和速度重新初始化位置规划器，同时保留重力轴DCE积分；从保持转入下一条路径时继续保留积分，避免旧规划器状态覆盖保持目标或产生瞬时力矩空档。只有显式09紧急失能才要求六轴全部关闭输出。编码器未校准、限位触发、堵转或其他本地安全故障轴仍保持无输出，其他健康轴继续抱住，不能用自动使能绕过保护。

前台浮点求1ms采样并预存63ms，20kHz中断只做整数插补、闭环和保护。最终位置保持闭环。F103CB栈3KB，链接静态RAM（含栈堆）约9.7KB/20KB，Flash约54KB/128KB。

error：1心跳超时；2未校准/限位/堵转/失能/起点不符；3非法曲线或超限；4前台采样断供。连续路径坐标在驱动板接收时已加编码器home偏移，启动检查直接使用绝对编码器坐标，不得重复叠加home。启动容差按节点减速比统一为0.5°关节角（J1～J6分别为3556/7111/7111/2133/2133/71内部步）；容差内把第一次执行的首段起点重对齐到启动瞬间的实测位置，后续段及循环闭合曲线不变，超过容差则报告起点不符。任一板故障时配套主控停止全部六板，健康轴继续保持位置闭环。无机械刹车流程。
