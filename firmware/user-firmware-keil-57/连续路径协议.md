# 无刹车42步进电机：五轴连续路径协议 v3

更新日期：2026-11-09。本固件直接驱动电机并使用板载编码器闭环。五块相同硬件可烧录同一个HEX，配套新版V6000主控和新版SmallProject上位机。

## 地址设置

J1/J2/J3/J4/J5对应节点1/2/3/4/5。上电从三个拨码读取ID，覆盖EEPROM中的节点号；不能仅靠保存CAN地址后不改拨码。

代码映射：Switch4/PA8=bit0，Switch3/PA9=bit1，Switch2/PA10=bit2；低电平为1。按有效位列出：

| 节点 | bit2 bit1 bit0 |
|---|---|
| 1 | 0 0 1 |
| 2 | 0 1 0 |
| 3 | 0 1 1 |
| 4 | 1 0 0 |
| 5 | 1 0 1 |

各板地址唯一，改拨码后重启。J6为虚拟固定轴，不使用节点6。各板保留自己的电流、编码器校准及零位设置，不能用一块板的校准数据覆盖另一块板。

## CAN协议

标准ID=node<<7|command，1Mbps；float为小端IEEE754，seq/session为小端uint16。

| 命令 | 数据 | 作用 |
|---|---|---|
| 0D | DLC2 session | 停止清空并建立新会话 |
| 0A | DLC8 p0,p1 float（电机圈） | 一段起终点 |
| 0B | DLC8 v0,v1 float（圈/秒） | 一段起终速度 |
| 0C | DLC8 时间float,seq,session | 提交段，seq从0连续，最多32段 |
| 3C请求 | DLC0 | 查询状态并喂500ms心跳看门狗 |
| 3C响应 | 03,state,count,index,error,05,sessionLo,sessionHi | 协议3，能力05=板载编码器+连续路径 |
| 39请求 | DLC0 | 能力响应03,05,20,00,00,00,00,00 |
| 广播66 | FF,66,03,mask,count,repeat,sessionLo,sessionHi | 选中节点同步启动，延迟20ms |
| 09 | 兼容原停止长度 | 停止并清除路径 |
| 23 | DLC0 | 原累计多圈编码器float及finished反馈 |

mask bit0～bit4=节点1～5，五轴1F，J2/J3为06。不在mask内的节点忽略启动。只有正确版本、会话、段数及已校准/起点允许时才能启动。旧两字节FF66的单次同步兼容保留；旧八字节协议2不再启动新版连续运动。

0C在CAN中断暂存，前台验证时间、速度、加速度、p/v连续性后增加count。主控核对所有参与板count/session再装下一段，整条路径装完才广播启动。超限拒绝，不会单轴静默降速破坏同步。速度、电流、加速度沿用各板EEPROM限制。

## 执行与保护

BufferedPath为五次Hermite执行器，各段端点加速度0；初始速度0，最后速度0；循环须位置和速度闭合。当前上位机循环每圈末停车。所有轴共用段时间；运动中不依赖网络逐段追发。

前台浮点求1ms采样并预存63ms，20kHz中断只做整数插补、闭环和保护。最终位置保持闭环。F103CB栈3KB，链接静态RAM（含栈堆）约9.7KB/20KB，Flash约54KB/128KB。

error：1心跳超时；2未校准/限位/堵转/失能/起点不符；3非法曲线或超限；4前台采样断供。启动编码器距起点≤1024内部步（0.02电机圈）。任一板故障时配套主控停止全部五板。无机械刹车流程。
