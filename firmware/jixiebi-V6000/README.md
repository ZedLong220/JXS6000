# JXS6000 六轴 CAN 主控 v4

更新日期：2026-11-09。配套上位机为 HMIcode/SmallProject-6000，驱动固件为 user-firmware-keil-57。

## 硬件和轴映射

六块相同的无刹车42步进驱动板直接驱动电机，各自使用板载编码器闭环。J1～J6分别对应CAN节点1～6，同一驱动HEX可烧录全部六板，拨码地址必须唯一；J6为实体CAN关节，范围-180°～180°。另有独立夹爪舵机由PA0输出PWM。

主控CAN1为PB8/RX、PB9/TX，1Mbps；USART1为PA9/TX、PA10/RX，115200 8N1。PC的USB转CAN与主控、六块驱动板接入同一总线。主控不再输出DM542脉冲或操作机械刹车。

上位机负责URDF正逆解、六轴路径规划和碰撞检查；主控负责逐帧确认、32段缓存、六板装载确认、同步启动、编码器监控及故障停止。不会上电自动运动或自动置零。

## 六轴主机协议

标准ID=(node<<7)|command；float为小端IEEE754，序号和会话为小端uint16。所有运动单位为电机绝对圈数/圈每秒，不是关节角度。

| 节点0命令 | DLC | 数据与作用 |
|---|---|---|
| 50 | 2 | 04,参与轴位图；清空旧路径并开始事务 |
| 51 | 5 | 节点1～6,起点float；每个参与轴发送一次 |
| 52 | 6 | 段时间float,段序号uint16；开始一段 |
| 53 | 8 | 节点,kind,段序号uint16,数值float；kind=0目标，1出口速度 |
| 54 | 2 | 段序号uint16；全部参与轴目标与速度配齐后提交 |
| 3A | 1 | 00清空，01执行一次，02闭合循环 |
| 09 | 0或兼容原长度 | 停止全部六轴 |
| 04 | 至少4 | 前4字节为0时兼容停止 |
| 15 | 兼容原长度 | 停止并将全部六轴当前位置保存为home |
| 38 | 状态响应8 | state,error,onlineMask,movingMask,count,index,axisMask,04 |

所有位图bit0～bit5对应J1～J6。六轴=3F；保留J2/J3固定测试=06。非零参与轴必须在3F内。时间0.05～120秒，最多32段；未完成的一段1500ms过期。长度、序号、有限数值或参与轴检查失败返回NAK；非法段数据会废弃当前未提交段。运动期间拒绝新路径。起点必须先配齐，未提交段不能启动。

每条已识别主机命令回复节点0/3B：
确认计数uint16、原始ID uint16、原始DLC、校验字节、接受标志、保留字节。
校验为ID低字节 XOR ID高字节 XOR DLC XOR 所有数据字节。3B仅表示主控接受该帧，不表示电机已到位。查询帧不会当成编码器反馈，也不会在共享CAN上重复转发。

USART1支持SLCAN S8/O/C/t标准帧，普通CR只是串口接收确认。SLCAN模式调试打印转USART2。旧文本move:j2_rev,j3_rev,time_s和旧60/61、62/63/64/66/68保留为J2/J3兼容入口；新上位机使用50～54协议。

## 驱动执行和同步

主控先检查所有参与节点在线、起点误差≤0.02电机圈，再逐板发0D建立新会话。每段使用0A起终点、0B起终速度、0C时间/序号/会话预装。每段等待所有参与板3C返回协议4、能力05、正确会话和段数，才继续。旧固件或缺板不会启动。

全路径预装完成后再次核对起点，广播：
FF 66 04 mask count repeat sessionLo sessionHi
驱动仅在自身节点被mask选中时执行，延迟20ms后以本地20kHz时钟运行。中间段不等待CAN指令或finished。所有轴共用每段时间，名义上同控制节拍结束；独立晶振的实机时钟误差仍需测量。

五次Hermite/Bezier衔接位置、速度、加速度连续。普通拐角局部圆滑，默认约1mm几何容差；精确反向、首末点停车。循环在每圈回起点处停车，再本地开始下一圈。属于关节空间路径，不能当作笛卡尔直线插补；1mm规划界不包含编码器跟踪、减速比和装配误差。

运动每20ms查询参与轴23编码器和3C心跳；空闲每200ms查询六轴23。3C内部反馈不再转发串口，减少带宽占用。最终所有板state=3、启动后新反馈finished=1、位置误差≤0.01电机圈，才报告完成。

状态：0空闲、1缓存、2等待编码器/装载、4运动、5最终到位检查、7故障。
错误：1发送/队列失败，2编码器超时，3最终到位超时，4协议/装载/路径反馈超时，5驱动故障，6起点不符。
启动和每次装载等待1500ms；运动反馈超时750ms；总时间额外5000ms仍不到位则停止。驱动500ms失去心跳或采样断供也会独立停止。任一参与轴故障时向节点1～6全部发送09。

## PA0夹爪PWM

按指定HAL舵机例程使用TIM2_CH1/PA0，仅配置PA0，不占用PA1。TIM2时钟84MHz，PSC=83、ARR=19999，50Hz，CCR单位1µs。角度0～180对应500～2500µs，上电CCR=0无脉冲。

节点0命令55：DLC4角度float；56：DLC0关闭PWM；57：DLC0查询状态。均逐帧3B确认，非法角度/NaN/Inf/长度返回NAK。状态响应57为8字节：角度float、脉宽uint16、启用标志、版本1。响应是已接受的指令值，不是舵机测量反馈。CAN停止不自动关闭夹爪PWM，避免意外松爪。

源码USER/Src/gripper_servo.c负责验证、映射和状态，Core/Src/tim.c负责硬件。舵机用额定电源供电并共地，PA0仅接信号。
