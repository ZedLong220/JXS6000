# JXS6000 机械臂上位机

Windows WPF 上位机，包含串口 / CAN 控制、基于 URDF 的正逆运动学，以及与本地网页一致的三维预览与碰撞检测。

## 发布与运行

- 开发和发布电脑需要 .NET SDK；目标电脑不需要安装 .NET Runtime。
- 目标电脑仍需要 Microsoft Edge WebView2 Runtime。
- 在本目录运行：

```powershell
dotnet publish SmallProject/SmallProject.csproj -c Release -p:PublishProfile=win-x64-self-contained
```

发布结果位于 `publish/win-x64-self-contained`。复制到其他电脑时必须复制整个目录，不能只复制 `SmallProject.exe`。运行该程序启动上位机；添加 `--check-model` 参数可执行不连接硬件的模型自检。旧命令脚本已清理。

自包含发布已包含 .NET 7 x64 Desktop Runtime、Viewer、URDF/STL、图标、ONNX 模型和 NuGet 本机依赖。HALCON 功能仍需要目标电脑具备相应的 HALCON Runtime/授权；使用 ONNX GPU 功能时仍需要匹配的显卡驱动和 CUDA 运行环境。

`SmallProject/Viewer` 已包含可离线使用的三维页面和6000模型。修改页面源码后，在安装 Node.js 的机器运行：

```powershell
cd ViewerSource
npm ci
npm run build
```

模型坐标、零位、角度转换和碰撞边界见 `JXS6000适配说明.md`。

## 六轴联动

配套仓库根目录的 `firmware/jixiebi-V6000` 主控和 `firmware/user-firmware-keil-57` 驱动。六块无刹车42步进驱动板使用同一个驱动HEX，拨码节点分别1～6，对应J1～J6；J6范围-180°～180°。

单点使用“运动勾选轴”，支持1～6轴任意组合；记录至少两个点位后使用“勾选轴点位连续运动”。详细规划容差、循环方式、协议和验证结果见 `连续路径更新说明.md`。

## 任意组合关节运动

J1～J6角度输入框旁的勾选框表示该轴参与本次运动。修改角度会自动勾选对应轴，也可以手动勾选或取消。例如只设置并勾选J2/J3/J4/J5后点击“运动勾选轴”，四轴按同一段时间联动，只要求这四个节点在线。目标0°同样有效；角度仍是相对零位的绝对目标。未勾选任何轴时不会发送运动指令。

未勾选轴保持当前位置，其输入框即使留有旧目标也不会下发。刷新位置、预览或运动完成不会自动增加勾选轴，当前选择保留供下次使用；逆解计算成功会勾选六轴，可再手动取消。路径继续进行限位和碰撞检查，非参与轴使用最近读取的位置，首次为模型0°。现有协议4主控和驱动已支持任意参与轴位图，无需为此重新刷固件。

## 单轴和多轴点位记录

调试时只需接入需要的驱动板，手动勾选对应J轴，点击“记录勾选轴”。无需填写目标角度；程序只查询并等待所选轴的新编码器位置。未勾选轴不会导致缺板超时；所选轴缺失反馈则不保存本次点位。运动中不允许记录或同时开始另一项操作。

点位表的“记录轴”列标明实际记录的关节，未记录轴显示“—”，实测0°仍显示0。部分轴点位不显示末端位姿，避免将非实测位置当作完整姿态。旧格式点位按完整六轴记录兼容读取。

记录至少两个点位后，勾选本次需要运行的轴，点击“勾选轴点位连续运动”。每条点位都必须记录这些轴，否则会提示具体行和缺失关节，请补录或删除不适用记录，也可取消不需要的轴。未选轴在整段路径中保持本次起始位置，不会使用点位中的缓存值。可勾选“循环（回起点）”往返调试；只等待参与轴的编码器及最终到位反馈。

点位连续运动的“圆滑 / mm”默认20，范围1～50。值越大允许越宽的拐角过渡，通常可减少拐点减速，但不会精确经过每个记录点；精度优先可设1。该值是关节插补路径映射到末端的规划几何容差，不包含实机跟踪误差。完整圆滑曲线仍通过限位、碰撞和穿地检查。

2026-11-14 移除与前一位置相同的重复点（包括循环末点与启动位置重合时的多余等待段），并限制电机轨迹的加速度变化率以减少拐点冲击；普通反向位置和每圈回启动位置仍减速，真实换向不能强行保持非零速度。连续运动会自动调整段时间以满足速度、加速度及加速度变化率限制。仅更新上位机即可使用，不需要为此刷写固件。

## 速度与减速比设置

按实机将J1～J6默认减速比设为50/100/100/30/30/1。系统设置中的关节速度默认60°/s、电机限速15圈/s、电机加速度23圈/s²、平滑限制（加速度变化率）500圈/s³。单轴和多轴均使用这些参数；23圈/s²是根据当前驱动板成功/拒绝曲线的边界留出的兼容上限。

点击“应用”保存后，速度参数在下一次运动时生效，减速比修改需重启；运动、上传或记录期间不能应用参数。编辑设置但未应用时不会改变实际规划。电机限速可设大于0至30，加速度大于0至23，平滑限制大于0至5000；系统只调整上位机规划，不修改驱动板EEPROM。若板内限速或加速度更低，驱动会拒绝超限曲线，应按板内参数降低规划限制。

以J1/J2/J3的三点(10,10,10)→(-10,-10,30)→(0,0,0)、上述实机减速比、3mm圆滑范围做软件基准，旧参数一圈9.043s，新参数3.734s，约2.42倍规划速度。实际速度仍取决于点位距离、拐点、负载及驱动能力。新增5503项规划/协议检查、实际WPF碰撞检查及三轴驱动执行器三圈模拟通过；未连接实机测量提速效果。

2026-11-13 按现有六轴相线接法，所有轴相对原方向统一反向：J1～J6的模型角度到电机圈数方向为 `-/+/-/+/-/-`（原为 `+/-/+/-/+/+`）。方向集中在 `SmallProject/Devices/Arm/Kinematic/MotorCoordinateMap.cs`，构造motorJ后同时用于目标、路径速度和编码器反馈换算。

2026-11-14 根据实机观察将URDF的J1～J6旋转轴全部反向，使三维模型正方向与电机实际运动一致；非对称限位同步镜像为J2 `-180°～250°`、J3 `-330°～180°`。目标、反馈、正逆解和碰撞检查共用新模型。仅需更新上位机，无需重新烧录主控或驱动板。

更新后先用单轴小角度确认六个关节的实物方向。原版本记录的非零点位对应的电机目标方向已改变，需要重新核对或记录，不能直接按旧点位循环。

## 单轴运动

只接一块驱动板时，在右侧操作区下方选择“单轴：J1～J6”（默认J3），在上方对应的J轴输入框填写目标关节角度，再点击“单轴到目标”。角度是相对已设置零位的绝对目标，不是本次增量；保持目标不变再次点击不会再转同样角度。速度沿用系统设置，按减速比换算电机圈数。

单轴模式只等待所选节点的新编码器反馈，并通过协议4的参与轴位图只装载、启动该轴，例如J3为0x04。现有主控和驱动固件已支持，不需重新烧录。保留路径限位、碰撞、停止和最终编码器到位检查；非参与轴使用最近读取的位置，首次默认为模型0°，缺板时这些位置无法实测。勾选全部六轴时仍要求全部六个节点在线。

2026-11-13 启动检查优化：完整路径已覆盖首段时只检查一次；相邻区间不重复检查公共端点。碰撞粗筛改用缓存局部包围盒，精确表面相交仍使用原BVH；接近地面时回退到原顶点判断，采样间距和地面容差保持一致。130组实际模型姿态与原算法的结果一致。

本机离线基准：J3 10°检查由约1679ms降至约65ms，150°由约23811ms降至约369ms；发布版实际WPF/WebView检查分别为40ms和331ms。这些时间不含编码器查询、逐帧确认和驱动启动，实机总延迟以新增的路径准备分阶段日志为准。可在ViewerSource运行 `node scripts/benchmarkValidation.mjs` 复测，无串口或电机指令。

本机保留已生成的发布目录。Git只上传可构建源码、必要资源及预构建Viewer，不提交发布依赖、开发缓存、日志和个人运行数据。未使用的5000模型和临时PDF提取脚本已移出项目备份。

## PA0夹爪舵机

夹爪区使用主控PA0/TIM2_CH1的50Hz PWM，角度0°～180°对应500～2500µs。上电无脉冲，点击发送角度或0°/180°按钮后启用；可关闭PWM或查询状态。状态为指令角度和脉宽，不是舵机位置反馈。舵机按额定电压供电并与主控共地，PA0接信号线。机械臂停止保留夹爪当前PWM，关闭输出需要显式点击。

## 本机服务配置

服务凭据不随仓库分发：

- 小智接入点：环境变量 `XIAOZHI_MCP_ENDPOINT`，或运行目录的 `DATA/Config.data` 内的 `EndpointUrl`。
- 阿里云语音：环境变量 `DASHSCOPE_API_KEY`、`DASHSCOPE_WORKSPACE_ID`、`DASHSCOPE_APP_ID`。
- B 站直播参数默认留空，根据自身账号配置。

`DATA`、日志、IDE 缓存、构建产物和 `node_modules` 已排除提交。所需 ONNX 权重、URDF、STL 和预构建三维页面保留在仓库内。
