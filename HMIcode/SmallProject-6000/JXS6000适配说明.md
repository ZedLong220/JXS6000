# JXS6000 上位机适配

当前模型资源来自 2026-11 提供的 `JXS6000-stl` 目录。STL 使用毫米和整机装配坐标，CAD 的 +Y 方向映射到 URDF 的 +Z；底座安装面位于 URDF Z=0。

S1 为固定底座，S2～S6 对应 `link_1`～`link_5`。按实际六轴控制启用 `joint_6`，范围为 -180°～180°，对应CAN节点6；沿用现有末端法兰轴线。未提供独立法兰及夹爪STL，因此该轴仍无独立网格，夹爪PWM也不虚构几何和质量参数。

关节原点与轴线由 STL 接合圆柱和装配面提取：J1 为底座竖直轴，J2/J3/J4 为平行的俯仰轴，J5 使用末端接合面的 20° 法向，J6 沿末端工具方向。2026-11-14 根据实机观察将六个URDF轴相对原CAD约定全部反向，使模型正方向与实际运动一致。零位末端位置仍为 X=57.5 mm、Y=86.73 mm、Z=372.6 mm，RPY=(0°,0°,0°)。

正逆解从 `Viewer/URDF/jxs6000.urdf` 读取，不再使用旧 JXS5000 的尺寸。原控制程序仍使用六个角度，并保留既有电机坐标零位 `(0,0,180,0,-90,0)` 到模型零位的换算；这只是软件兼容映射，不代表新机械结构已经完成实机标定。

三维模型零位不需要额外的碰撞白名单。方向反转后的模型输入范围为J2 -180°～250°、J3 -330°～180°、J5 -90°～360°。J2/J3的非对称范围随方向镜像，碰撞与穿地拦截保持启用；允许输入整个限位范围不代表所有关节组合均无碰撞。电机协议仍保留J3的+180°、J5的-90°零位偏移，因此发送层范围分别对应J3 -150°～360°、J5 -180°～270°。当前网格逐度检查确认J4从-140°到50°、J5全行程可通过；J4=60°会触发腕部与上臂碰撞，J4=-155°会触发腕部与前臂碰撞。碰撞检查使用离散STL网格，只用于预览与软件拦截，不能替代实机限位、急停和标定。

修改三维源码后在 `ViewerSource` 运行 `npm test` 与 `npm run build`，再将 `dist` 内容同步到 `SmallProject/Viewer`。C# 运动学验证使用 `dotnet run --project Tests/KinematicsChecks.csproj`。
