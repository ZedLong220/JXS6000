# JXS6000 上位机适配

当前模型资源来自 2026-11 提供的 `JXS6000-stl` 目录。STL 使用毫米和整机装配坐标，CAD 的 +Y 方向映射到 URDF 的 +Z；底座安装面位于 URDF Z=0。

S1 为固定底座，S2～S6 对应 `link_1`～`link_5`。实体装配为五个旋转轴；为兼容上位机、CAN 控制和既有六关节数据结构，URDF 保留无独立 STL 的 `joint_6` 与 `tool0` 法兰坐标轴。

关节原点与轴线由 STL 接合圆柱和装配面提取：J1 为底座竖直轴，J2/J3/J4 为平行的俯仰轴，J5 使用末端接合面的 20° 法向，J6 沿末端工具方向。零位末端位置为 X=57.5 mm、Y=86.73 mm、Z=372.6 mm，RPY=(0°,0°,0°)。

正逆解从 `Viewer/URDF/jxs6000.urdf` 读取，不再使用旧 JXS5000 的尺寸。原控制程序仍使用六个角度，并保留既有电机坐标零位 `(0,0,180,0,-90,0)` 到模型零位的换算；这只是软件兼容映射，不代表新机械结构已经完成实机标定。

三维模型零位不需要额外的碰撞白名单。J2 的模型输入范围为 -250°～180°，J3 为 -180°～330°，J5 为 -90°～360°。这个 J2/J3 外扩范围超过连续无碰撞边界，仅用于允许更大的关节输入；碰撞与穿地拦截保持启用。实际 STL 检查中，J2=-250°会使 link_2 穿地，J3=330°在零位附近会使 link_3 与底座相撞，因此危险组合不会通过路径校验。由于电机协议仍保留 J3 的 +180°、J5 的 -90°零位偏移，发送层范围分别对应 J3 0°～510°、J5 -180°～270°。当前网格逐度检查确认 J4 从 -50° 到 140°、J5 全行程可通过；J4=-60°会触发腕部与上臂碰撞，J4=155°会触发腕部与前臂碰撞。碰撞检查使用离散 STL 网格，只用于预览与软件拦截，不能替代实机限位、急停和标定。

修改三维源码后在 `ViewerSource` 运行 `npm test` 与 `npm run build`，再将 `dist` 内容同步到 `SmallProject/Viewer`。C# 运动学验证使用 `dotnet run --project Tests/KinematicsChecks.csproj`。
